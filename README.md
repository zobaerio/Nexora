# NEXORA — A Photorealistic Living Universe

NEXORA is an original virtual civilization: a realistic 3D world where people live complete simulated lives — childhood, education, careers, families, homes, businesses, cities, an economy, dynamic weather, and eventually other planets.

**This is not a GTA clone and uses no other game's assets, code, maps or branding.** It is an original universe, built in phases where every phase ends with a tested, playable build.

## The phases

1. Photorealistic environment test → 2. MetaHuman character → 3. Movement/camera/interaction → 4. Day-night & weather → 5. First living city district → 6. NPC society & economy → 7. Life stages & families → 8. Multiple cities → 9. Persistent multiplayer → 10. Planets

## First city

**Rupsha City** — a Bangladeshi-inspired city (rickshaws, CNGs, tea stalls, riverfront) inside the NEXORA universe.
